# Trait Index (all KeyForge traits, alphabetical)

Traits extracted from `master-vault-data/packs/*.json`. Verified count: 98 distinct traits (99 raw strings; `"elf "` in DT.json is a trailing-space duplicate of `elf`). Houses shown are the houses that carry cards with that trait (lowercase house keys as in the pack JSON: brobnar, dis, ekwidon, logos, mars, redemption, saurian, sanctum, shadows, skyborn, staralliance, unfathomable, untamed). "First" is the earliest set file in repo data that introduced the trait.

Bonus pips and DM "Enhance" mechanics are covered in [10-pips-enhancements.md](10-pips-enhancements.md); keywords (taunt, elusive, etc.) are covered in `../01-core-rules/07-traits-and-keywords.md`.

## A

- **[redacted]** - first AoA; houses: logos. Literal REDACTED joke creature (Logos); no rules interaction.
- **adagion** - first AS; houses: skyborn. Skyborn episode-part tag (companion entity); no direct hooks.
- **agent** - first AoA; houses: mars (+ later sanctum, dm, mg24 appearances). Secret operative; Mars plot hooks.
- **ai** - first AoA; houses: logos, geistoid. Artificial-intelligence units; Logos/Geistoid constructs.
- **alien** - first DM; houses: skyborn, sanctum, staralliance, mars, shadows, brobnar, redemption. Generic off-world species, introduced by DM.
- **ally** - first AoA; houses: mars, saurian. Coalition members; cooperation hooks.
- **analyst** - first AS; houses: ekwidon. Data/investment professionals (Ekwidon).
- **angel** - first AoA; houses: sanctum, redemption. Divine servants; Sanctum healing/duty hooks.
- **aquan** - first DM; houses: unfathomable, shadows, staralliance, brobnar. Aquatic mirror-world species.
- **arm** - first DT; houses: unfathomable. Disembodied arm (Deep, DT-era); part-of-creature tag.
- **artisan** - first AS; houses: ekwidon, skyborn, mars. Crafters.
- **assassin** - first AS; houses: skyborn, saurian, shadows. Killers.
