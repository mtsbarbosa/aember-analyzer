## Engine Mechanics

- **Haunted**: player-level state flag; `isHaunted()` returns true while at least 10 cards lie in your discard pile (with a purged-count variant), per `server/game/player.js:767`. Example: `server/game/cards/07-GR/AbductOMatic.js` (post-fight capture only `if (...) context.source.controller.isHaunted()`).
- **Scrap**: discard-pile action keyword (`this.scrap({...})`, same file).

## Gameplay Notes

- Geistoid runs on discard-pile interaction: your discard becomes an active zone, so scrap/haunted triggers reward filling and re-reading it.
- Versatile is the first keyword that lets a card operate cross-house every turn (soft house independence), directly increasing turn flexibility.
- Note on user query: "prophetic" mechanics are NOT from this set. Prophecy belongs to set 12 (`12-PV.json`, type `prophecy`); GR offers scrap/haunted/versatile instead.
